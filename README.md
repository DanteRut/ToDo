# Momentum

Персональная система действий: быстрый план дня, параллельные цепочки действий, привычки, тренировки и синхронизация между устройствами.

## Что уже работает

- экран «Сегодня» с одним ясным следующим шагом;
- параллельные цепочки действий внутри даты, зависимости и блокировка шагов;
- drag-and-drop порядка и перенос действий между цепочками;
- полное редактирование, перенос, копирование и удаление цепочек;
- заготовки цепочек сохраняют настраиваемые подготовки и создают их перед выбранными действиями;
- быстрый планировщик с автоматическим расчётом времени действий;
- умный следующий шаг, ручной выбор фокуса среди сегодняшних и просроченных действий, режим «Сейчас» и фокус-таймер;
- звуковое окончание таймеров с пользовательским `public/sounds/timer-end.mp3` и встроенным резервным сигналом;
- повторяющиеся задачи, подзадачи, теги, энергия, фильтры и обработка просроченного;
- месячный, недельный и дневной календарь;
- расписание пар УВП-412 с автоматическим чередованием первой/второй недели, отображением на «Сегодня» и в календаре;
- домашние задания, привязанные к конкретной паре и дате, с ручным планом на день и прогрессом только по выбранным на этот день заданиям;
- настраиваемые привычки, серии, 21-дневная история и процент выполнения;
- редактируемый 4-дневный сплит, лог веса/повторений/RIR и таймер отдыха;
- добавление и удаление подходов прямо во время активной тренировки;
- подробная история тренировок: каждый подход, вес, повторения, RIR, объём, длительность и заметка;
- графики прогресса веса и тренировочного объёма;
- глобальные «Входящие» для мгновенной фиксации мыслей;
- утренний настрой и вечерний обзор дня;
- расчёт реальной нагрузки с учётом пар и 50 минут на сборы и дорогу до вуза;
- единый таймлайн задач, пар, дороги, ДЗ и ритуалов со свободными окнами;
- иерархические проекты и подпроекты (например, Учёба → Предмет), учебные дедлайны и автоматическая разбивка большой работы на этапы;
- утренний ритуал с выбором только основных задач и благодарностью, вечерний — с уроком, исправлением сбоя и медитацией намерения;
- свёрнутые цепочки в «Плане», настраиваемые заготовки, выбор задач и перенос задач или целых цепочек;
- раздельные даты планирования и дедлайна, статусы «ожидание»/«когда-нибудь» и обратное планирование этапов;
- фиксированные и гибкие блоки, проверка конфликтов с парами/дорогой и предпросмотр расписания перед применением;
- автоматический перерасчёт времени цепочек; после наступления следующего дня незавершённые задачи освобождаются и остаются просроченными, а завершившаяся цепочка удаляется; шаблон при этом не меняется;
- пошаговая обработка Входящих, меню перемещения без drag-and-drop, архив задач и проектов; при закрытии цепочки из заготовки копии подготовок удаляются, заготовка остаётся, остальные задачи возвращаются в свободный план без архива;
- план/факт фокус-времени, журнал отвлечений, быстрые Входящие в режиме «Сейчас» и переход к следующему шагу;
- аналитические выводы, защита от перегрузки, история версий задач и явное разрешение облачных конфликтов;
- восстановление активной тренировки, таймеров и черновиков;
- причины переносов, измерения самочувствия и браузерные уведомления;
- ежедневные локальные снимки с восстановлением последних 7 версий;
- offline-first хранение в IndexedDB;
- защищённая синхронизация через Supabase;
- экспорт и импорт полной JSON-копии;
- 13 мгновенно переключаемых цветовых тем: монохромные, аналоговые, комплементарные, триадные, натуральные и сплит-комплементарные;
- installable PWA для iPhone и desktop.

## Настройка общей базы для iPhone и компьютера

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor**, вставьте содержимое [`supabase/schema.sql`](supabase/schema.sql) и нажмите Run.
3. В **Project Settings → API** скопируйте Project URL и публичный `anon` key.
4. В приложении откройте **Облако**, вставьте эти два значения и создайте аккаунт.
5. На втором устройстве откройте приложение, укажите тот же проект Supabase и войдите с тем же email и паролем.

`anon` key является публичным ключом фронтенда. Безопасность данных обеспечивает Row Level Security: пользователь может читать и менять только строки со своим `user_id`. Никогда не добавляйте `service_role` key в приложение или GitHub.

### Автоматическая конфигурация при деплое

Приложение содержит публичные URL и publishable key Supabase по умолчанию, поэтому вводить настройки вручную не нужно. Для другого Supabase-проекта можно переопределить их в GitHub **Settings → Secrets and variables → Actions** переменными `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` — они применяются при сборке и имеют приоритет над значениями по умолчанию.

Publishable/anon key предназначен для клиентского приложения; безопасность данных обеспечивает Row Level Security. Никогда не встраивайте `service_role` key или другие административные секреты во фронтенд.

В Supabase добавьте адрес GitHub Pages в **Authentication → URL Configuration → Redirect URLs**.

## GitHub Pages

Workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) собирает и публикует приложение автоматически. В репозитории выберите **Settings → Pages → Source → GitHub Actions**, затем запустите workflow или отправьте новый commit.

## Архитектура синхронизации

Изменения сначала сохраняются локально, поэтому интерфейс работает без сети. При подключении они отправляются в таблицу `records`. На новом устройстве сначала загружаются облачные записи, благодаря чему демонстрационные данные не создают дубли. Удаления передаются как tombstone-записи, а конфликтующие изменения разрешаются по времени обновления.
