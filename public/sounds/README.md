# Timer sound

Place the completion sound here as:

`timer-end.mp3`

Recommended encoding: MP3, 44.1 kHz, 128–192 kbps, 1–4 seconds long. Keep the file reasonably small (preferably below 500 KB) so the PWA downloads and caches it quickly.

If the file is missing or cannot be played, Momentum uses its built-in three-note Web Audio signal.
